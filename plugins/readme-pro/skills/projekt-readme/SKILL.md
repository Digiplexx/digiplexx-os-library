Prüfe zuerst die vorhandene README, Manifeste, Konfiguration und relevante Einstiegspunkte. Ermittle Zweck, Voraussetzungen, Installation, Start und Tests aus dem Projekt. Wenn ein Befehl oder eine Funktion nicht belegt ist, lass sie aus oder markiere die offene Frage.

Überarbeite ein vorhandenes README mit möglichst kleinen Änderungen. Bewahre projektspezifische Inhalte, Links und Lizenzhinweise. Zeige auf Wunsch zuerst den Entwurf. Führe Beispielbefehle nur aus, wenn der Nutzer einen praktischen Test anfordert. Fasse am Ende zusammen, welche Angaben du aus dem Projekt prüfen konntest.
